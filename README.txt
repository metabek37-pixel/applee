APPLE STORE CLONE — demo loyiha

Ishga tushirish:
1. ZIP faylni oching.
2. apple-store-clone papkasini VS Code orqali oching.
3. index.html faylini brauzerda oching (yoki Live Server ishlating).

Fayllar:
- index.html — sayt tuzilishi
- style.css — dizayn va animatsiyalar
- script.js — filtr, carousel, mahsulot oynasi va ro‘yxatdan o‘tish

Eslatma:
- Mahsulot narxlari va ayrim texnik xususiyatlar demo ma’lumotlari.
- Ro‘yxatdan o‘tish shakli front-end demo: ma’lumotlar serverga yuborilmaydi yoki saqlanmaydi.
- Mahsulot rasmlari tashqi internet manbalaridan yuklanadi; rasmlar ko‘rinishi uchun internet kerak.
- Bu Apple’ning rasmiy sayti emas, mustaqil o‘quv clone loyihasi.
